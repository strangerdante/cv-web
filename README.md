# Hoja de Vida Web - Jamel Alan Pimienta Beltrán

Versión web interactiva y responsiva de la hoja de vida de Jamel Alan Pimienta Beltrán (Desarrollador Front End Junior), construida con estándares web modernos.

## 🚀 Tecnologías utilizadas

- **HTML5 semántico**: Estructura fiel al documento original de vida.
- **CSS3 vanilla**: Diseño responsive, variables CSS, soporte para tema oscuro/claro y estilos optimizados para impresión (`@media print`).
- **JavaScript vanilla**: Lógica ligera para alternar temas, copiar datos de contacto al portapapeles e imprimir / exportar a PDF.

## 📋 Características

- 🌓 **Modo Oscuro / Claro**: Detección automática del tema del sistema y persistencia mediante `localStorage`.
- 🖨️ **Listo para imprimir**: Ajustado para exportar a PDF o imprimir en tamaño carta respetando márgenes y jerarquías sin elementos innecesarios.
- 📋 **Copiar Correo al Portapapeles**: Notificación interactiva tipo toast al copiar el correo.
- 📱 **Totalmente responsivo**: Adaptable a smartphones, tablets y pantallas de escritorio.
